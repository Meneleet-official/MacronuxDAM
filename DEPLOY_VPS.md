# 🚀 Установка и управление ботом Macronux™ (PMX) на Linux VPS

В проект встроены:
1. **[`install.sh`](install.sh)** — автоматический установщик для любого Linux VPS (Ubuntu, Debian, AlmaLinux, Rocky, CentOS, Fedora, Arch).
2. **[`botctl.sh`](botctl.sh)** (глобальная команда **`pmx`**) — удобная интерактивная панель и CLI-утилита для управления ботом на сервере.
3. **[`Dockerfile`](Dockerfile) + [`docker-compose.yml`](docker-compose.yml)** — альтернативный запуск в Docker-контейнере одной командой.

---

## Вариант 1: Быстрая установка на VPS (Systemd + панель `pmx`) — Рекомендуется

### Шаг 1. Подключитесь к VPS по SSH
```bash
ssh root@ВАШ_IP_СЕРВЕРА
```

### Шаг 2. Загрузите бота на сервер
**Способ А — через Git (рекомендуется для удобных обновлений):**
```bash
git clone https://github.com/Meneleet-official/MacronuxDAM.git /opt/pmx-bot
cd /opt/pmx-bot
```

**Способ Б — копирование папки с вашего ПК (через SCP / WinSCP / FileZilla):**
Выполните в PowerShell на вашем ПК:
```powershell
scp -r f:/Code/DAP root@ВАШ_IP_СЕРВЕРА:/opt/pmx-bot
```
Затем на самом VPS перейдите в папку:
```bash
cd /opt/pmx-bot
```

### Шаг 3. Запустите автоматический установщик
```bash
bash install.sh
```
**Что сделает `install.sh` автоматически:**
1. Определит вашу ОС и установит `python3`, `python3-venv`, `pip`, `git`, `sqlite3`.
2. Создаст изолированное окружение `.venv` и установит все библиотеки из `requirements.txt`.
3. Если `.env` ещё не заполнен — запустит пошаговый мастер и спросит `BOT_TOKEN`, провайдера ИИ (`groq` / `gemini` / `deepseek` / `openrouter`) и API-ключ.
4. Создаст системную службу `/etc/systemd/system/pmx-bot.service` с автозапуском при перезагрузке VPS и авто-перезапуском при сбоях (`Restart=always`).
5. Добавит глобальную команду **`pmx`** (`/usr/local/bin/pmx`), чтобы вы могли управлять ботом из любой папки на сервере.

## 🛠️ Удобное управление ботом на VPS (команда `pmx`)

После установки вы можете просто ввести в терминале VPS:
```bash
pmx
```
Откроется интерактивное меню управления:
```text
====================================================
   🛡️  Панель управления ботом Macronux™ (VPS)
====================================================
 Состояние: ● РАБОТАЕТ
----------------------------------------------------
  1) Статус бота и сервиса (status)
  2) Живые логи в реальном времени (logs)
  3) Последние ошибки (errors)
  4) Статистика базы данных (stats)
  5) Перезапустить бота (restart)
  6) Запустить бота (start)
  7) Остановить бота (stop)
  8) Настроить .env / токены (config)
  9) Обновить бота из Git + бэкап (update)
 10) Создать резервную копию БД (backup)
 11) Восстановить из резервной копии (restore)
  0) Выход
----------------------------------------------------
```

### Быстрые команды без входа в меню:
| Команда | Описание |
| :--- | :--- |
| `pmx status` | Показать статус бота, аптайм, потребление памяти и размер БД |
| `pmx logs` | Смотреть живые логи бота в реальном времени (`Ctrl+C` для выхода) |
| `pmx errors` | Показать только последние ошибки и предупреждения |
| `pmx stats` | Вывести статистику из SQLite прямо в терминал (нарушения, наказания, топ правил) |
| `pmx restart` | Мягко перезапустить бота (с сохранением прогресса сканирования) |
| `pmx stop` / `pmx start` | Остановить или запустить бота |
| `pmx config` | Открыть `.env` в редакторе `nano` и сразу перезапустить бота |
| `pmx update` | Сделать авто-бэкап БД, скачать обновления (`git pull`), обновить пакеты и перезапустить |
| `pmx backup` | Сделать «горячий» бэкап базы `modbot.db`, телеметрии и `.env` в папку `backups/` |
| `pmx restore` | Восстановить базу данных и настройки из архива бэкапа |

## Вариант 2: Запуск через Docker Compose (альтернативный)

Если на вашем VPS установлен Docker:

1. Скопируйте `.env.example` в `.env` и укажите ваш `BOT_TOKEN` и API-ключ:
   ```bash
   cp .env.example .env
   nano .env
   ```
2. Запустите контейнер в фоновом режиме:
   ```bash
   docker compose up -d --build
   ```
3. Управление контейнером:
   * Логи: `docker compose logs -f`
   * Перезапуск: `docker compose restart`
   * Остановка: `docker compose down`
   * База данных и логи сохраняются на хосте в папке `./data`.
